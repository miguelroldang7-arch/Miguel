# TicketFix

Sistema web para la gestión de solicitudes de soporte técnico dentro de una empresa o institución. Permite a los usuarios reportar incidencias, a los técnicos darles seguimiento y a los administradores visualizar el estado general del servicio.

## Objetivo
Centralizar el registro, seguimiento y resolución de tickets de soporte técnico.

## Arquitectura
Arquitectura por capas (presentación, lógica de negocio, datos) combinada con el modelo cliente-servidor.

## Componentes principales
- Interfaz Web (frontend)
- TicketController
- TicketService
- AuthService
- NotificacionService
- Base de Datos
